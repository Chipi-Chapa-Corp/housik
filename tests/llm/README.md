Run `npm run test:llm` explicitly to scan the three supplied photos. It loads `.env`: `OPENAI_API_KEY`, `OPENAI_MODEL`, and `OPENAI_RESPONSES_URL` (the full endpoint including `/responses`). Azure uses the deployment name as `OPENAI_MODEL`. Defaults are `OPENAI_MODEL=gpt-6.1-sol` and `OPENAI_REASONING_EFFORT=low`; an explicitly empty reasoning setting preserves the provider default. Photos are attached unchanged, without cropping.

This is a comparison report, not a Node test runner. Extraction differences never throw assertions or return a failing exit status. Each receipt shows **Numbers match** or **Numbers differ**, product counts, currency totals, and side-by-side line comparisons. Only amounts, currencies and line counts affect the numeric status. Names are informational, with changed characters highlighted red for expected and green for actual. Lines are compared in receipt order, including duplicate lines. `null` currency uses the application's CZK default.

Each run writes `.test-data/llm/N.actual.json`, a plain `.diff.txt` and a colored `.diff.html` report. Terminal colors are automatic; use `FORCE_COLOR=1` to force them or `NO_COLOR=1` to disable them. Reports include every line without truncation. Configuration or provider failures print a concise message without a stack trace and may return status 1; numeric differences return status 0.

Every API call records input, cached-input, cache-write, output, reasoning and total tokens, duration, response ID, model, reasoning effort, pricing rates and estimated USD cost. Reasoning tokens are a subset of output tokens and are not charged twice. Current metadata is saved in `N.call.json`; `.test-data/llm/calls.jsonl` appends one record per call. Each run is also archived under `runs/RUN_ID/`, including a snapshot of previous reports. Missing usage or unknown prices are shown as unavailable rather than zero.

For GPT-6.1 Sol with up to 272K input tokens, estimates use [OpenAI Standard reference rates](https://developers.openai.com/api/docs/pricing): $2 input, $0.10 cached input, $2.50 cache writes (30m), and $10 output per million tokens. Azure billed rates may differ; unknown long-context Sol pricing remains unavailable unless rates are configured.

For GPT-6 Luna, estimates default to published [Global Standard USD rates](https://azure.microsoft.com/en-us/blog/gpt-6-astra-sol-and-luna-for-production-agents-in-microsoft-foundry/): $0.10 input, $0.01 cached input, $0.125 cache writes, and $0.50 output per million tokens, with long-context rates above 272K input tokens. Regional deployment, service tier, tax or contract charges can differ. Override your billing rates with `OPENAI_INPUT_USD_PER_MILLION`, `OPENAI_CACHED_INPUT_USD_PER_MILLION`, `OPENAI_CACHE_WRITE_USD_PER_MILLION`, and `OPENAI_OUTPUT_USD_PER_MILLION`. Input, cached-input and output overrides must be supplied together. Cache-write pricing is required if cache writes are reported.
